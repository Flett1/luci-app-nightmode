# luci-app-nightmode

Приложение LuCI для OpenWrt, предназначенное для автоматического управления светодиодами роутера по расписанию или вручную.

## Возможности

* **Ночной режим по расписанию:** автоматически выключает светодиоды в заданные часы.
* **Сохранение состояния:** сохраняет исходное состояние светодиодов в оперативной памяти (`/tmp/led_orig_brightness`), чтобы корректно восстановить активные светодиоды после выхода из ночного режима.
* **Интеграция с UCI:** настройки хранятся в `/etc/config/general`.
* **Лёгкость:** shell-демон с минимальной нагрузкой на систему.

## Статус

* **Работоспособность подтверждена** по состоянию на сентябрь 2026 года.

## Протестированное оборудование

* **CMCC RAX3000M** (MediaTek MT7981) — проверено на OpenWrt 25.12.5.

## Установка

### Простой способ установки

1. Скачайте и установите **WinSCP**.
2. Подключитесь к роутеру по его IP-адресу, используя имя пользователя `root` и пароль роутера.
3. Скопируйте оба `.apk` файла в каталог `/tmp` на роутере.
4. Подключитесь к роутеру через SSH.
5. Выполните следующую команду:

```sh
apk add --allow-untrusted /tmp/luci-app-nightmode-*.apk /tmp/luci-i18n-nightmode-ru-*.apk
```

После установки приложение появится в интерфейсе **LuCI**.

### Сборка из исходного кода в OpenWrt SDK

1. Перейдите в каталог OpenWrt SDK или дерева сборки.
2. Клонируйте репозиторий пакета:

```bash
git clone https://github.com/Flett1/luci-app-nightmode.git package/luci-app-nightmode
```

3. После этого пакет можно собрать с помощью OpenWrt SDK.
